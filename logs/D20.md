## 3. Flags

- **Crisis gate not met: 12 of 13.** Not tuned against the private statements; options in the Phase 2 report, section 4.
- **Subscription stand-ins understate Explain length.** Real API notes run about 50% longer, so the 97.5% is likely optimistic; the API sample passed 3 of 5.
- **Generation in batches is not identical to runtime.** Subagents wrote 20 notes or 125 rewrites per context; the runtime makes one call per item.
- **The rate limiter is in memory** and holds only on one server instance; Day 22 moves it to a shared store behind the same interface. **The Console's monthly spend limit is the final backstop.**
- **Explain trusts that the crisis check ran first.** The endpoint can be called directly; Day 22 adds the crisis check inside it too.
- **v2 changes the first-acceptable numbers** (human held-out 24 → 15) more than hit@3; read v1 and v2 figures separately.
- A Next.js quirk: `next.config.ts` needs `forceReload` to read the repository's root `.env`.
